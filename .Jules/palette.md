## 2024-03-24 - Semantic Form Labels in React Modals
**Learning:** In a single-file React application building DOM elements directly with `React.createElement`, standard accessibility practices like using semantic `<label>` elements with `htmlFor` instead of stylized `<div>`s remain crucial for screen reader support and keyboard accessibility. Additionally, icon-only buttons (`＋`, `✎`, `×`) and form inputs without visible labels (like the Add Project and Import fields) need explicit `aria-label` attributes to provide context to assistive technologies.
**Action:** Ensure all form controls inside modals and dynamic UI sections use proper `<label>` elements with matching `id`s, and proactively add `aria-label` attributes to any icon-only interactive elements or inputs relying solely on placeholders.
